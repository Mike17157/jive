# Audit retry behavior

Act as the engineer preparing an Apache Airflow retry cleanup for a central platform team. Explore the pinned source and tests in this workspace, classify retry-related candidate sites under the supplied policy, and follow promising candidates through their helpers, callers, state transitions, and tests before deciding whether they are actionable.

Deliver `work/findings.json` using the schema in `README.md` and a maintainer-facing `work/report.md`. Prioritize demonstrated behavior and bounded evidence. The report should distinguish correctness defects from migration opportunities, explain important rejected lookalikes, state coverage and unresolved dependency boundaries, and recommend an order for follow-up work. Do not modify the corpus.
